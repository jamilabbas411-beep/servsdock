# ServsDock static website

A responsive static website made with HTML, CSS, and browser-ready JavaScript. The pages are Home (`index.html`), Services, About, and Contact. Why Us and How We Work are sections on the home page.

## Preview and deployment

There is no build step or package installation. Open the project folder with a static file server (for example, VS Code Live Server) and visit `index.html`. Deploy the project files and folders to a static host, keeping the existing paths intact.

The site uses externally hosted Unsplash photos and Google Fonts.

## Contact form limitation

The contact form validates in the browser and displays a preview confirmation; it does not send or save submissions. Connect a form service or backend before using the site to collect inquiries.
